# Tavo 工程定位

从目标项目的根规则和最近的功能合同确定维护目录。按交付物查入口、负责实现的模块、依赖方、测试和实际打包命令。

- TPG 插件从 `manifest.json`、入口模块、UI 源与本地化资源定位。先查 builder，再判断哪些 HTML、资源清单和 TPG 归档属于生成物。
- 记忆相关插件分别核对数据 owner、模型配置、存储命名空间、迁移逻辑和生命周期 hooks。
- 应用、插件、命令工具及各宿主集成通常拥有独立的验证和发布流程。读取实际配置，核对任何后置脚本的副作用。
- 归档、旧版和已交付制品可用于核对历史。维护规则和本次验收以当前目标源码和运行结果为准。
