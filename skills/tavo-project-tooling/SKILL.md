# Tavo 项目工具链

先拿到目标工作区、工具入口、操作目标或实际命令与症状。分清索引结果、维护源、验证器和产品行为，先读当前注册位置、直接代码、调用方与命令配置，按实际写入、网络和宿主动作判断权限。单独的 Graphify 查询、建图、更新或导出走 `$tavo` 的 Graphify 分支。此处处理它与项目的注册、输入或消费关系。

| 目标 | 先查 / 最小动作 |
| --- | --- |
| 全局技能发现和自动触发 | 对照当前目录下的客户端发现结果、命中的 `SKILL.md` 和 `agents/openai.yaml`。分别核对项目同名技能、模型自动选择、显式调用和 `$tavo` 读取子分支。核对发现结果后，再用场景验证实际分支选择。 |
| 项目共享技能、官网镜像或项目链接校验 | 根规则 → 实际技能 Registry、文档来源清单 → 项目注册的资源校验脚本。检查报错对应文件是否存在、引用从哪个目录解析、清单或哈希是否匹配。按项目规则更新已变更的项目资源及对应清单。 |
| Project Map / RAG / KG / Graphify | 仅当目标实际具有该工具并且任务需要时定位其入口和当前输入。先查现有索引身份/新鲜度，结果只供寻找真实 owner；不为普通工作重建地图、不启动 watcher。遵守当前项目的显式调用要求。 |
| Hook、注册脚本、验证器、打包辅助 | 看实际注册、作用目录、参数/前后置脚本、写入目标和退出码。先小输入/预览，修改在源码 owner；避开带发布或宿主动作的校验路径。 |
| 制品分发、归档、任务工具 | 项目工作流负责判定交付状态和归档条件。工具实际注册且操作获授权后，核对真实路径、写入范围、回滚和需保留的数据。 |

先用最小输入复现或预览，遇到入口缺失或权限不足时交付已核实的注册与输入证据、缺项和受影响范围。修复时改维护源，用已有命令再生受影响的索引或清单，复跑相同输入和直接消费者的必要检查。

交付工具 owner、操作目录、命令和最小输入、预期与实测输出或退出码，以及仍受影响的调用方或门禁。仅诊断时标明结论的证据和未验证项。若发现实际问题属于产品，把症状和证据交回工程；若工具结果用于仓库验收，把结果交回项目工作流判定状态。
