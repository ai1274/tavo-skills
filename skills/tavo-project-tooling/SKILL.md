# Tavo 项目工具链

先确定故障层：**索引返回错**、**实际 owner 不存在**、**验证器判定错** 与 **产品本身有缺陷**不是同一件事。读当前注册位置、直接代码、调用方与命令配置；按实际 side effect 分类，不从脚本名字推断只读。

| 目标 | 先查 / 最小动作 |
| --- | --- |
| 全局技能发现和自动触发 | 查指定全局 `SKILL.md`、`agents/openai.yaml` 和 Codex 的发现结果；可用 `skill-router.py search` 核对候选。项目同名技能和显式调用单独检查。检索命中不是实际模型使用。 |
| 项目共享技能/官网镜像/项目链接 | 根规则 → 实际技能 registry、文档来源清单 → 项目注册的资源校验脚本。只在项目资源变更时同步当前清单和哈希；全局技能不走项目同步。 |
| Project Map / RAG / KG / Graphify | 仅当目标实际具有该工具并且任务需要时定位其入口和当前输入。先查现有索引身份/新鲜度，结果只供寻找真实 owner；不为普通工作重建地图、不启动 watcher。遵守当前项目的显式调用要求。 |
| Hook、注册脚本、验证器、打包辅助 | 看实际注册、作用目录、参数/前后置脚本、写入目标和退出码。先小输入/预览，修改在源码 owner；避开带发布或宿主动作的校验路径。 |
| 制品分发、归档、任务工具 | 只有当前项目实际注册且任务授权才操作；先确认真实路径、写入范围、回滚和需保留的数据。 |

先证明少量输入能稳定复现问题，修正唯一 owner，再检查直接消费者、受影响清单/哈希与必需门禁。不要手改生成索引、混用项目与全局注册表、让 Hook 代替人工授权、或把辅助工具输出当业务合同。并发只给独立只读检查；有共享输出或外部影响时串行。
